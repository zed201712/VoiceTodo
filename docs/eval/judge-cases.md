# 判斷階段測試句

用來比較不同 AI（自動 AI、手動 AI）的判斷成效。先打開除錯 UI 的**測試清單**開關（見 [storage](../specs/storage.md) 的「測試清單」），每題從**重新開始**（換回下面的測試待辦）起，依序輸入「句子」欄；「預期」是判斷階段應輸出的 JSON（[格式](../specs/judgment.md)）。日期必須是公開的寫法（見 [todos](../specs/todos.md) 的「日期」）。

測試待辦（測試清單打開、重新開始時建立；M 是這個月，M+1 是下個月）：

| 日期 | 時間 | 內容 |
|---|---|---|
| M/3 | | 繳電話費 |
| M/12 | 15:00 | 看牙醫 |
| M/18 | 09:00 | 部門會議 |
| M/25 | | 買牛奶 |
| M+1/2 | | 買牛奶 |
| M+1/9 | 09:00 | 部門會議 |
| M+1/16 | | 媽媽生日 |
| M+1/28 | | 繳房租 |

比對方式：打開測試清單 → 重新開始 → 切換成手動 AI（評估手動 AI 時）→ 把句子貼進測試輸入 → 依序處理 AI 請求（一般判斷可以批次，見 [judge-prompt](judge-prompt.md)）→ 複製測試紀錄。

## 提示頁的範例句

提示頁（見 [help](../specs/help.md)）裡只靠 AI 判斷才認得的說法；單元測試檢查每一句都列在這裡。

| # | 句子 | 預期 |
|---|---|---|
| 34 | 新增明天買牛奶 | `{"commands":[{"action":"新增待辦","date":"明天","content":"買牛奶"}]}` |
| 34b | 新增今天下午3點買牛奶 | `{"commands":[{"action":"新增待辦","date":"今天下午3點","content":"買牛奶"}]}` |
| 34c | 新增10月10日上午9點看牙醫 | `{"commands":[{"action":"新增待辦","date":"10月10日上午9點","content":"看牙醫"}]}` |
| 34d | 買牛奶改到後天 | `{"commands":[{"action":"修改待辦","keyword":"買牛奶","newDate":"後天"}]}` |
| 34e | 買牛奶完成 | `{"commands":[{"action":"設定完成","keyword":"買牛奶","isDone":true}]}` |

「下週五台北天氣如何」見 #32b。

## 提示還沒凍結時

先說「提示」打開總導覽，再輸入「句子」。請求多一行 `提示：總導覽（連結：新增、修改、刪除、顯示）`。只和連結名稱完全相同的話由規則判斷處理，不送 AI，所以這裡只放其他說法。

| # | 句子 | 預期 |
|---|---|---|
| 35 | 顯示那個點進去 | `{"commands":[{"action":"說明","page":"顯示"}]}` |
| 35b | 我想看刪除的說明 | `{"commands":[{"action":"說明","page":"刪除"}]}` |
| 35c | 新增明天買牛奶 | `{"commands":[{"action":"新增待辦","date":"明天","content":"買牛奶"}]}` |

## 釐清後判斷

先輸入「前一句」，App 提出釐清後再輸入「句子」。預期的是釐清後判斷的輸出。測試待辦的部門會議在這個月 18 日與下個月 9 日；#15 以 2026 年 9 月測試為準，其他月份把「10月9號」換成下個月 9 日。

| # | 前一句 | 句子 | 預期 | 來源 |
|---|---|---|---|---|
| 15 | 部門會議完成了（找到多筆） | 10月9號那個 | `{"commands":[{"action":"設定完成","date":"10月9日","keyword":"部門會議","isDone":true}]}` | user story 6、尚未驗證 |
| 16 | 部門會議完成了（找到多筆） | 算了，下週有什麼事 | `{"commands":[{"action":"查詢待辦","date":"下週"}]}` | 回答變成新需求 |
| 16b | 部門會議完成了（找到多筆） | 不要了 | `{"commands":[{"action":"聽不懂"}]}` | 不要做這件事（取消），不是復原 |

## 刪除確認

先輸入「前一句」進入刪除確認，再輸入「句子」。關鍵字（好、不要…）比對得到的不會送 AI，所以這裡只放比對不到的回答。

| # | 前一句 | 句子 | 預期 |
|---|---|---|---|
| 17 | 刪除下次的買牛奶 | 好啊刪吧 | `{"answer":"yes"}` |
| 18 | 刪除下次的買牛奶 | 等一下 | `{"answer":"no"}` |
| 19 | 刪除下次的買牛奶 | 不好 | `{"answer":"no"}` |
| 20 | 刪除買牛奶（找到多筆） | 全部都刪掉 | `{"answer":"yes"}` |
| 21 | 刪除 11月9號（找到多筆） | 刪除買牛奶 | `{"answer":"other"}`，之後的釐清後判斷輸出 `{"commands":[{"action":"刪除待辦","date":"11月9日","keyword":"買牛奶"}]}` |
