# 日期與時間

## Problem Statement

使用者用各種說法講日期和時間（「下禮拜五」「晚上7點以後」「下午1點到3點」）。AI 會把話改寫成公開的寫法，但換算成實際的日期與時間有固定規則，要由日期與時間解析完成，結果才可靠。

同一個時間說法在不同用途下意思不同：新增「明天晚上看電影」的「晚上」是一個時間點（18:00），查詢「明天晚上有什麼事」的「晚上」是一段時間（18:00 以後）。

## Solution

日期與時間的通用規則：和這個專案的功能無關，換到別的 App 也成立。日期與時間分成兩個欄位解析、各自保留，都可以沒有；預設值與用途由呼叫的一方決定（各指令怎麼用見 [todos](todos.md)）。

- **日期解析**（`DatePhrase`）：日期的語法與換算。
- **時間解析**（`TimePhrase`）：時間的語法、有效性，以及依用途換成時間點或範圍。

兩者都是業界說的 parser（解析器）。

一句話：**AI 照公開的寫法填，規則從大到小解析；日期和時間分開，用的時候才決定預設值與換成點還是範圍。**

## User Stories

1. 作為使用者，我想用平常的說法講日期與時間，規則換算出正確的日期。
2. 作為使用者，我想問「晚上有什麼事」時看到整個晚上的待辦，新增「晚上看電影」時是晚上 6 點。
3. 作為使用者，我想用「8點以前」「1點到3點」「7點以後」問一段時間。
4. 作為開發者，我想看到日期與時間解析切出的每個單位與換算結果，AI 填錯時一眼看出錯在哪。

## Implementation Decisions

### 語法

date 是一個字串，由下列單位依順序組成（大到小），每個單位只接受公開的說法。語法要完整寫進 AI 的提示詞；使用者的說法不同時，由 AI 改寫成公開的寫法，不換算成實際日期。

```
日期 = 單點 | 單點~單點 | 下次 | 目前 | 所有
單點 = [年][月][週][日][時間]   至少一項，照這個順序
  年：去年、今年、明年、YYYY年
  月：上個月、這個月、下個月、M月
  週：上週、本週、下週
  日：前天、昨天、今天、明天、後天、D日、週一～週日
  時間：時刻 | 時刻以前 | 時刻以後 | 點到點
    時刻：時段 | [時段]H點[M分]
    點到點：時刻到時刻
    時段：凌晨、清晨、上午、早上、白天、中午、下午、晚上
```

**AI 的寫法**：「號」寫成「日」；「星期」「禮拜」寫成「週」（「下禮拜五」→「下週週五」）；數字用阿拉伯數字；「半」寫成「30分」；「接下來」「接下來一週」「接下來七天」寫成「目前」；查詢時使用者明確說「所有」「全部的〇〇」才寫「所有」（其他指令的「所有」「全部」是畫面上顯示的全部，見 [todos](todos.md) 的「黑板」）；單位之間不留空白。日期範圍用「~」，時間範圍用「到」。

**解析的方式**：從最大的單位開始，比對到一個單位就拿掉那段字，再比對較小的單位；只能往小的單位走。順序不對（「15日下個月」）、同一個單位出現兩次、或剩下比對不到的字，就不合法。

**解析結果**：日期與時間解析回傳切出來的各單位與換算結果，例如 `下個月 15日 下午 3點 30分 → 2026/11/15 15:30`、`明天 晚上 7點 以後 → 2026/10/04 19:00 以後`、`下個月 → 2026/11/01 ~ 2026/11/30`。不合法時回傳已經切出來的部分與卡住的字，例如 `下個月 15日 → 看不懂「下午X」`。完整的分析記在測試紀錄；回話只顯示換算結果，不合法時原因是 `看不懂「下午X」`（見 [ui](ui.md)）。

### 日期

- 範圍是最小單位的整段：「明年」整年、「明年1月」整月、「下週」整週、「下週週五」「明天」一天。「目前」是今天起 7 天（也是黑板範圍的特例，見 [todos](todos.md) 的「沒說日期時：以黑板為準」），「下次」是今天起最早符合的一筆那一天，「所有」不限日期。
- 沒說的較大單位：沒說年就是今年；「D日」沒說月就是這個月；「週X」沒說週就是本週。一週從星期一開始。
- 不合法的組合：相對的日（前天～後天）前面有年、月或週；「週X」前面有年或月；週前面有年或月；「D日」接在週後面；時間不是接在一天之後（例如「下個月下午」）；說法不在清單上、日期不存在（「2月30日」）。
- **日期範圍** `單點~單點`：兩邊都要是日期（不含時間）。結束早於開始、而且結束沒寫年時，結束算明年（「12月10日~1月10日」是 2026-12-10 到 2027-01-10）；算明年之後仍然早於開始就不合法。
- 只有時間、沒有日期時，日期是「沒有」，由呼叫的一方決定預設（見 [todos](todos.md)）。

### 時間

**時段加上 H點**：

| 時段 | H點 | 例子 |
|---|---|---|
| 凌晨、清晨 | 照原樣，H 是 0～12 | 凌晨3點 03:00、清晨7點 07:00 |
| 上午、早上、白天 | a.m.：照原樣，H 是 0～12 | 早上8點 08:00 |
| 中午 | H 小於 6 加 12 | 中午12點 12:00、中午1點 13:00 |
| 下午、晚上 | p.m.：H 是 1～12，小於 12 加 12 | 下午3點 15:00、晚上7點 19:00 |
| 沒有時段 | H 是 0～23 | 15點 15:00 |

- 「晚上12點」不合法：它是隔天 00:00，會跨日。
- 分是 0～59。
- 時段和 H點 是不同的資訊：「下午」沒有時間資訊，「下午3點」有。

**依用途換算**：同一個說法，日期與時間解析依呼叫的一方要的用途換成時間點或範圍。

| 說法 | 時間點（新增、修改的新時間） | 範圍（查詢、找目標） |
|---|---|---|
| 凌晨 | 不合法 | 00:00 以上、未滿 06:00 |
| 清晨 | 06:00 | 06:00 以上、未滿 09:00 |
| 上午 | 09:00 | 00:00 以上、未滿 12:00 |
| 早上 | 09:00 | 09:00 以上、未滿 12:00 |
| 白天 | 09:00 | 06:00 以上、未滿 18:00 |
| 中午 | 12:00 | 12:00 以上、未滿 15:00 |
| 下午 | 15:00 | 12:00 以上、未滿 18:00 |
| 晚上 | 18:00 | 18:00 以後 |
| H點[M分] | 那個時間 | 剛好那個時間 |
| 時刻以前 | 不合法 | 未滿那個時間（不含） |
| 時刻以後 | 不合法 | 那個時間以後（含） |
| 點到點 | 不合法 | 兩端都含 |

- 「時段以前／以後」的邊界是時段範圍的開頭：「中午以前」是未滿 12:00，「下午以後」是 12:00 以後。
- 點到點的兩端是時間點：時段用它的時間點（「中午到下午」是 12:00 到 15:00，凌晨沒有時間點所以不合法）；後半只有 H點 時沿用前半的時段（「下午1點到3點」是 13:00 到 15:00）。結束早於開始就不合法。
- 範圍不含沒有時間的待辦（見 [todos](todos.md) 的「資料」）。

**下一個時段**：給呼叫的一方用的函式，依傳入的現在時間回傳下一個時段的時間點：

| 現在 | 下一個時段 |
|---|---|
| 未滿 06:00 | 06:00 |
| 06:00 以上、未滿 09:00 | 09:00 |
| 09:00 以上、未滿 12:00 | 12:00 |
| 12:00 以上、未滿 15:00 | 15:00 |
| 15:00 以上、未滿 18:00 | 18:00 |
| 18:00 以後 | 沒有 |

### 結構

日期解析與時間解析都是 Domain 層的純函式，不依賴黑板、存檔與現在時間（今天、現在由呼叫的一方傳入）。解析的結果保留日期與時間的說法本身，換算成點或範圍、套用預設，都在用的時候由呼叫的一方決定。

## Testing Decisions

- 單元測試（macOS），固定「今天」與「現在」：
  - 日期：解析的順序與拿掉的字、解析結果的文字、每種組合（含月份、範圍、跨年），包括今天是星期日時的「本週週一」「下週週一」「週一」、具體日期、「下次」「所有」，以及每種不合法的組合。
  - 時間：每個時段加 H點 的換算與範圍（晚上12點、下午13點、早上13點不合法）；時間點與範圍兩種用途的換算表；以前、以後、點到點的邊界；點到點沿用前半的時段、結束早於開始不合法；時段以前／以後的邊界；下一個時段的每一列。

## Out of Scope

- 跨日的時間範圍（「晚上10點到凌晨2點」）
- 時區
