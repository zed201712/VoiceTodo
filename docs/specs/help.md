# 提示

## Problem Statement

第一次用的人不知道該怎麼說。原本問用法時由 AI 聊天依使用說明自己組句子：每次措辭不同、要等 AI，回答也沒有下一步可以點。頂端的便條只顯示待辦的現況，黑板本來就看得到，沒有教使用者下一句可以說什麼。

## Solution

使用說明寫成固定的**提示頁**。問用法時，小精靈回一個**提示對話框**：外觀是小精靈的回話，裡面是一頁提示，可以用箭頭換頁、點藍色的連結跳到其他頁，也可以用說的換頁。換頁都在同一個泡泡裡進行，不讓對話流變長；下面出現新的泡泡後它就**凍結**。

叫出、翻動提示頁是一個執行器（**說明**），規則判斷認得固定的說法，AI 判斷也能輸出它；不在任何一頁裡的問題才交給 AI 聊天。

頂端的便條改成**引導**：依剛才聽不懂的話、還沒用過的操作與黑板的狀態，告訴使用者下一句可以說「如何○○」。

一句話：**問用法時小精靈回固定的提示頁，可以點、可以說；便條告訴新手下一句可以問什麼。**

## User Stories

1. 作為第一次用的使用者，我想按一個按鈕或說「提示」，就看到最基本的四種操作怎麼說。
2. 作為使用者，我想說「如何新增」，直接看到新增可以照著說的句子。
3. 作為使用者，我想點提示裡的「新增」，或在提示還開著時直接說「新增」，就換到新增那一頁。
4. 作為使用者，我想用箭頭或說「下個提示」翻頁，翻頁時對話流不變長、箭頭不移動。
5. 作為使用者，我想說了小精靈聽不懂的話之後，便條告訴我可以問什麼。
6. 作為新手，我想便條依我還沒做過的操作，一步一步告訴我下一個可以學的。
7. 作為使用者，我想不需要時可以關掉便條。
8. 作為使用者，我想問「我不知道怎麼把事情加進去」這種自然的話，也能看到新增那一頁。

## Implementation Decisions

### 提示頁

每一頁是幾行固定的文字，以可以照著說的句子為主（「」裡的話），盡量短。**連結**嵌在文字裡（下表的 `[頁名]`），藍色粗體，點了換到那一頁，像網頁的超連結。頁的順序就是箭頭的順序，最後一頁的下一頁是總導覽，總導覽的上一頁是最後一頁。

| # | 頁名 | 內容 |
|---|---|---|
| 1 | 總導覽 | [新增]：說「新增明天買牛奶」<br>[修改]：說「第1項改到明天」<br>[刪除]：說「刪除第1項」<br>[顯示]：說「顯示明天」<br>說「關閉音效」，我就不再念出聲音。<br>說「下個提示」看其他用法。 |
| 2 | 新增 | 說「新增今天下午3點買牛奶」。<br>說「新增10月10日上午9點看牙醫」。<br>沒說日期，就加在黑板上那天；日期怎麼說見[日期說法]。 |
| 3 | 修改 | 說「第1項改到明天」。<br>說「第1到3項延到下週一」。<br>也可以說內容：「買牛奶改到後天」。<br>說「第1項複製到明天」，原本的會留著。<br>什麼是[編號]？ |
| 4 | 刪除 | 說「刪除第1項」「刪除第1到3項」。<br>說「刪除全部」刪黑板上的全部，說「刪除完成」刪已完成的。<br>刪之前我會先問，說「好」才刪。<br>什麼是[編號]？ |
| 5 | 顯示 | 黑板顯示目前的範圍，修改、刪除只找黑板上的待辦。<br>說「顯示明天」「顯示下週」換範圍。<br>說「顯示全部」看所有日期。<br>也可以[翻頁]、看[完成]的。 |
| 6 | 完成 | 說「完成第1項」，或點待辦前面的方框。<br>也可以說內容：「買牛奶完成」。<br>說「顯示完成」「隱藏完成」，或點右上角的勾勾。<br>黑板範圍裡過去的待辦都會顯示。 |
| 7 | 編號 | 黑板每行最前面的數字是編號。<br>說「第3項移到明天」「完成第2項」「刪除第5到10項」。 |
| 8 | 翻頁 | 說「上一頁」「下一頁」，回到看過的黑板。<br>黑板沒有上一頁、下一頁時，換成翻提示。<br>說「上個提示」「下個提示」也能翻提示。 |
| 9 | 查日期 | 說「週五幾號」「明天星期幾」。<br>只說「幾號」，查黑板那天。 |
| 10 | 天氣 | 說「明天會下雨嗎」「今天會下雨嗎」。<br>也可以說「下週五台北天氣如何」。 |
| 11 | 復原與重做 | 說「復原」回到上一步，說「重做」再回來。<br>也可以按下面的箭頭。<br>說「全部取消」，還沒處理的話都不做。 |
| 12 | 聲音與麥克風 | 說「停止」停下這次的報告。<br>說「關閉音效」不再念，說「打開音效」再打開；右上角的喇叭也可以切換。<br>查詢只念前3項，說「全部念完」就都念。<br>說「關閉語音」停止聆聽；要再打開，按下面的麥克風按鈕。 |
| 13 | 日期說法 | 日期說「10月12」「明天」「下週五」「下個月」。<br>時間說「下午3點」「晚上」，也可以不說。 |
| 14 | 畫面 | 黃色加粗的是今天。<br>標題後面藍色的字是查詢條件，灰色加刪除線的是已完成。 |
| 15 | 設定 | 按右上角的齒輪，可以選要用的 AI、填 Gemini 的 API key。 |
| 16 | 判斷失敗 | 說「重試」再試一次，說「略過」跳過。<br>聽不懂時，換個說法再說一次。 |

- 念、畫面資訊與聊天用的是頁裡的文字，連結只留頁名（「什麼是編號？」）。
- 每頁最多 6 行文字：提示對話框的高度以最長的一頁為準，要放得進對話流；放不下就拆頁。
- 頁裡「」裡的說法，要能被規則判斷或關鍵字認出來，或列在 [judge-cases](../eval/judge-cases.md) 裡由 AI 判斷實測過。
- 頁名不能和既有的固定說法相同（例如不用「復原」「全部取消」當頁名），否則還沒凍結時說頁名會和原本的意思衝突；衝突時原本的意思優先。
- 每頁另外有一個比對用的正規表達式，給聊天的補充資訊與便條的「剛聽不懂」用（見 [chat](chat.md) 的「補充資訊」、本文的「便條」）。
- 畫面的顏色與分組和 [ui](ui.md) 的「黑板」一致，改畫面時一起改。

### 說明（執行器）

| 指令 | 欄位 | 行為 |
|---|---|---|
| 說明 | 頁名 | 顯示那一頁 |
| 上個提示、下個提示 | 無 | 顯示目前那一頁的上一頁、下一頁 |

由小精靈執行，不改變待辦，不記 undo 狀態，不找目標、不移動黑板。

**顯示到哪裡**：

- 最底下的提示對話框還沒凍結：**原地換頁**。
- 沒有還沒凍結的提示對話框：在對話流最底下開一個**新的**提示對話框。上個提示、下個提示的起點是最後一個凍結的提示對話框停的那一頁；對話流裡沒有提示對話框時，打開總導覽。

**這句話在對話流**：一句話的指令全部是說明、上個提示、下個提示，而且會原地換頁時，這句話不出現在對話流，也沒有另外的回話，換頁就是回饋。其他情況照一般的話：這句話的泡泡出現（這時上面的提示對話框就凍結了），回話是新的提示對話框。一句話裡還有其他指令時，提示頁的文字接在回話裡，不是提示對話框。

**觸控**（效果和說的相同，照上面的規則原地換頁或開新的）：

| 觸控 | 等於 |
|---|---|
| 提示對話框的左、右箭頭 | 上個提示、下個提示 |
| 提示對話框裡的連結 | 說明（那個頁名） |
| 工具列的提示按鈕 | 說明（總導覽） |
| 點便條 | 便條上那句話 |

觸控開的新提示對話框和其他觸控的回話一樣，接在對話流最後（見 [ui](ui.md) 的「對話流」）。目前的結果正在執行或還沒解讀好時，執行中的回話還會更新，所以不能開新的（提示按鈕與便條不能點）；原地換頁不受限。

**上一頁、下一頁借用**：說「上一頁」「下一頁」（指令上一頁、下一頁）時，黑板沒有上一頁、下一頁，就改成執行上個提示、下個提示（見 [todos](todos.md) 的「黑板」）。黑板的上一頁、下一頁按鈕不變：沒有可以去的頁時仍然不能點。

### 提示對話框

- 外觀是小精靈的回話（插畫 `elf_done`），**高度固定**：以最長的一頁為準，換頁時不變；不在框內捲動，放不下的內容要拆頁。
- 文字下面固定一列：左箭頭（`chevron.left`）、`目前頁／總頁數`、右箭頭（`chevron.right`）。箭頭一直可以點（頁會循環），點擊範圍至少 44pt。
- 連結與箭頭用藍色，和泡泡的對比至少 4.5:1。連結是文字裡的超連結，大小跟著文字，不要求 44pt。凍結時連結不用藍色。
- **凍結**：提示對話框下面出現新的泡泡（使用者的話、小精靈的回話，包括觸控產生的回話）時就凍結：停在當時那一頁，箭頭與連結不能點。排隊的話、正在說的話不算。所以對話流裡最多只有一個還沒凍結的提示對話框，而且一定是最後一則。
- 語音報告念出目前這一頁的內容。提示頁顯示出來，這個結果就結束，念的期間後面的結果照常輪到（見 [queue](queue.md) 的「報告顯示時間」）；換頁或下一個結果輪到時，中斷正在念的那一頁（見 [spoken-report](spoken-report.md)）。念的期間說連結名稱、「下個提示」不會被當成回音（見 [queue](queue.md)）。

### 判斷

- **規則判斷**的句型（見 [judge-tool](judge-tool.md) 的「提示」）：
  - 「提示」「幫助」「說明」「怎麼用」「怎麼使用」「如何使用」→ 說明（總導覽）
  - `如何<頁名>`、`怎麼<頁名>`、`<頁名>怎麼用` → 說明（那一頁）
  - 「上個提示」「下個提示」
  - 還沒凍結的提示對話框目前那一頁的**連結名稱**（整句完全相同）→ 說明（那一頁）
- **AI 判斷 ** 知道說明、上個提示、下個提示這三個指令與頁名的清單（見 [judgment](judgment.md)）。問 App 怎麼用時，對得到某一頁就輸出說明；對不到才輸出聽不懂，交給聊天。
- 最底下的提示對話框還沒凍結時，一般判斷的請求多一行 `提示：<頁名>（連結：<連結名稱，以、分隔>）`（沒有連結時只有 `提示：<頁名>`），讓 AI 判斷知道使用者看到哪一頁（見 [judgment](judgment.md) 的「判斷的來源」）。這是 AI 判斷第一次收到畫面上的內容；改了之後要用 [judge-cases](../eval/judge-cases.md) 重新實測。
- 判斷在背景進行，用的是定稿時的快照；輪到時提示對話框已經凍結，就照「顯示到哪裡」開新的。

### 便條

**目前隱藏**：畫面不顯示便條，工具列也沒有便條開關。它和開場問候的提示重複，又佔用工具列與對話流頂端的空間，資訊價值相對低。挑選規則與用過的紀錄保留（用過的紀錄決定新手階段）；畫面的部分註解掉，日後有其他訊息要置頂時可以沿用。以下是顯示時的規則。

對話流頂端的置頂便條（橘色圖釘、半透明底，位置與捲動的規則見 [ui](ui.md) 的「對話流」）只做引導：一行，告訴使用者下一句可以說什麼。從上往下挑第一個符合的：

1. **剛聽不懂**：最近一個輪到的使用者意圖沒有指令（聊天的回應或「聽不懂」）。用那句話比對各頁的正規表達式，命中就是「可以說「如何<頁名>」」（命中多頁取頁的順序最前面的），沒命中是「可以說「提示」看怎麼用」。之後有任何指令執行成功，就不再是這一條。
2. **還沒用過的操作**：照新增、顯示、修改、完成、刪除的順序，挑第一個還沒用過、現在用得上的：「可以說「如何<頁名>」」。黑板上沒有待辦時，只有新增、顯示用得上。
3. **都用過了**：「可以說「提示」看更多用法」。

- **用過**：那一類的指令執行成功過一次，包括觸控（點方框算設定完成）。顯示＝查詢待辦或顯示全部；刪除＝確認後刪除。存在 UserDefaults，App 重開後接著用。
- **點便條**：等於說出便條上「」裡的那句話（見「說明」的觸控）。
- **開關**：工具列的便條開關（打開 `pin.fill`、關閉 `pin.slash`，點擊範圍至少 44pt）。預設打開，狀態存在 UserDefaults。關閉時便條不顯示，對話從區域頂端開始。
- 便條不放進畫面資訊（見 [screen-info](screen-info.md)）。

### 新手階段

用過的紀錄全部是空的時是新手階段：開場問候的內容改成引導（見「開場問候」）。不用「存檔裡沒有待辦」判斷：開場問候要立刻顯示，那時提醒事項可能還沒讀完；從提醒事項帶進大量待辦的人，第一次也一樣不會用。

### 開場問候

開 App 時對話流的第一則回話（見 [ui](ui.md) 的「對話流」），由規則組成，不經過 AI，所以立刻顯示：

- 內容：一頁提示的文字，依提示頁的順序輪，每次開 App 換下一頁，輪完從頭開始。輪到第幾頁存在 UserDefaults，App 重開後接著輪。沒有時段問候。
- 新手階段：「如果不會用的話，你可以問「提示」、「怎麼使用」，我會告訴你更多技巧唷！」，不推進輪到的頁。
- 一般的回話，不是提示對話框：純文字，連結只留頁名（和念的文字相同），沒有箭頭、不會凍結。
- 插畫 `elf_done`（完成）。
- 不念：每次開 App 都說話會吵。
- 不放進畫面資訊（「小精靈說」）：送給 AI 判斷與校正的內容不因為開場問候而改變（見 [chat](chat.md) 的「前提」）。
- 只在開 App 時；重新開始（除錯 UI）不顯示。

### 紀錄

- 開場問候記一行「提示」：`開場問候：<頁名>`，新手階段是 `開場問候：新手`。
- 開新的提示對話框：照其他指令記「指令 i/n」（回報是那一頁的文字），另外記一行「提示」：`提示：<頁名>（新的）`。
- 原地換頁：「指令 i/n」的回報是 `提示：<頁名>（原地）`。
- 觸控記一行「觸控」：`提示：<頁名>（原地）` 或 `提示：<頁名>（新的）`。
- 念提示被換頁或下一個結果中斷時，「中斷」的原因是「換頁」或「下一個結果」。

### 結構

- 提示頁的資料（頁名、內容、連結、正規表達式）與便條的挑選規則是 Domain 層的純值與純函式；聊天的補充資訊用同一份資料。
- 提示對話框的狀態（目前那一頁、是否凍結）屬於對話流，和其他回話一起管理；小精靈決定什麼時候回話、什麼時候固定，凍結的規則與上個提示、下個提示的起點由對話流決定。

## Testing Decisions

- 單元測試（macOS）：
  - 提示頁：上面的表格和程式的頁一致（順序、頁名、每一行）；每頁的連結都是存在的頁名；頁名不和固定說法、關鍵字相同；「」裡的說法都命中規則判斷或關鍵字，或列在 judge-cases 的清單裡
  - 規則判斷：每種句型命中對的頁；連結名稱只在還沒凍結時、只比對目前那一頁
  - 原地換頁不產生泡泡；有新的泡泡（使用者的話、回話、觸控的回話）就凍結；排隊的話不會讓它凍結
  - 沒有還沒凍結的提示時：上個提示、下個提示從最後一個凍結的那一頁開新的；沒有提示時打開總導覽；說明開新的並顯示這句話的泡泡
  - 箭頭循環：最後一頁的下一頁是總導覽，總導覽的上一頁是最後一頁
  - 上一頁、下一頁：黑板有可以去的頁時照舊；沒有時換成上個提示、下個提示
  - 一句話裡還有其他指令時，照一般的話
  - 一般判斷的請求：還沒凍結時多一行提示，凍結或沒有時和原本相同
  - 便條：三條規則的順序；剛聽不懂時命中與沒命中；用過的紀錄（含點方框）存檔後讀回；黑板沒有待辦時跳過修改、設定完成、刪除；開關關閉時不顯示
  - 換頁時念新的一頁，中斷正在念的；說明的結果顯示就結束，念的期間說「下個提示」馬上換頁；念提示頁時說連結名稱不被當成回音
  - 開場問候：依提示頁的順序輪、輪完從頭開始；沒有時段問候；新手階段是引導的句子、不推進；開 App 時是對話流的第一則、插畫完成、不念、不在畫面資訊裡；輪到的頁存檔後讀回來接著輪
- 手動驗證：
  - [ ] 換頁時提示對話框的高度與箭頭位置不變；最長的一頁放得下（iPhone SE）
