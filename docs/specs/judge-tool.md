# 規則判斷

## Problem Statement

AI 判斷每句要 1～3 秒以上，也會誤判：查詢待辦被判成查詢日期、雜音被判成不用填欄位的指令（當時是建立或清除示範資料）。但很多句子的說法是固定的（「明天有什麼事」「顯示全部」「隱藏完成」），用規則就能確定意思，不需要 AI 推斷。

## Solution

**規則判斷**和 AI 判斷對等，在同一層：只產生指令，交給執行器。目的是補足 AI 判斷現在的速度與準確度，AI 夠快、夠準、夠便宜時就不需要（憲章 P2-1）。它和其他規則一樣必須完整、不會出錯：只有整句完全符合固定句型、參數能被工具完整解析時才命中。命中時直接取代那一次的 AI 判斷；沒命中就照原本的流程交給 AI，結果和沒有規則判斷時相同。

一句話：**能確定的句子不問 AI；不確定就照舊交給 AI。**

刪除確認的 yes／no 關鍵字（見 [judgment](judgment.md) 的「刪除確認」）是同一個概念：取代 AI 刪除確認的規則判斷。

## User Stories

1. 作為使用者，我想說「明天有什麼事」「顯示全部」這類固定的話時，小精靈馬上處理，不用等 AI。
2. 作為使用者，我想固定的話不會被 AI 誤判成別的指令。
3. 作為使用者，我想小精靈問問題時，我說了一個完整的新需求（「下週有什麼事」），小精靈直接照新需求做。
4. 作為開發者，我想在測試紀錄看到哪一句由規則判斷判斷、沒有經過 AI。

## Implementation Decisions

### 什麼時候調用

每一次要呼叫 AI 判斷或 AI 刪除確認之前（見 [flow](flow.md)）：

| 原本要呼叫的 AI | 規則判斷 | 命中時 |
|---|---|---|
| 一般判斷 | 在關鍵字之後、平行處理階段之前 | 直接執行指令；不做 AI 校正、不送判斷 |
| 釐清後判斷 | 在平行處理階段之前 | 句型是完整的指令，不會是回答，所以是新需求：原本的任務取消，執行新指令 |
| 刪除確認的判斷 | 在 yes／no 關鍵字之後 | 同上：原本的刪除取消，執行新指令 |

- 不調用：錯誤確認後重試（重做同一份使用者提示詞；會命中的話第一次就命中了）、聊天（判斷沒有指令才聊天，命中就不會走到）。
- 手動 AI 時一樣調用：規則判斷不是 AI；命中時不出現使用者提示詞。
- 比對的是規則校正拿掉空白後的句子（見 [correction](correction.md) 的「規則校正」），先去掉標點。

### 句型

整句完全符合才命中，多一個字都不算；結尾可以多一個「呢」「嗎」。`<日期時間>` 經過說法改寫後，要能被日期與時間解析完整解析（見 [date-time](date-time.md)），解析不了就不命中。

**查詢待辦**（指令：查詢待辦，date 是改寫後的 `<日期時間>`）：

- `<日期時間>有什麼事`、`<日期時間>有什麼事情`、`<日期時間>有什麼待辦`、`<日期時間>有什麼行程`、`<日期時間>有什麼安排`、`<日期時間>有哪些事`、`<日期時間>要做什麼`、`<日期時間>有事嗎`、`<日期時間>的待辦`、`顯示<日期時間>`、`查詢<日期時間>`
- 「有…」「要做什麼」開頭的句型可以沒有 `<日期時間>`（「有什麼事」）：沒有 date，範圍不變、清除查詢條件（見 [todos](todos.md) 的「沒說日期時」）。

**查詢日期**（指令：查詢日期）：

- `<日期>是幾號`、`<日期>是幾月幾號`、`<日期>是星期幾`、`<日期>是禮拜幾`、`<日期>幾號`、`<日期>星期幾`、`<日期>禮拜幾`
- `<日期>` 只有時間（「晚上是幾號」）不命中；沒有 `<日期>`（「是幾號」）時沒有 date，以黑板為準。

**固定的話**（整句完全等於）：

| 話 | 指令 |
|---|---|
| 顯示完成、勾選完成 | 設定顯示（完成勾選） |
| 隱藏完成、取消勾選完成 | 設定顯示（完成不勾選） |
| 刪除全部 | 刪除待辦（黑板上的全部，照樣進入刪除確認） |
| 刪除完成、刪除完成項目、刪除已完成、刪除已完成項目、清除完成項目 | 刪除待辦（只刪已完成的，照樣進入刪除確認） |
| 復原、上一步、undo | 復原 |
| 重做、下一步、redo | 重做 |
| 顯示全部、顯示所有資料 | 顯示全部 |
| 上一頁 | 上一頁 |
| 下一頁 | 下一頁 |
| 全部念出來、全部念完 | 全部念完 |
| 今天會下雨嗎 | 查天氣（今天，所在地） |
| 明天會下雨嗎 | 查天氣（明天，所在地） |

復原到全部念完這 6 種只在一般判斷之前比對，等回答時不比對：它們在等回答時有別的意思（錯誤確認的復原、要全部念完嗎的回答），刪除確認時說「復原」是不要刪，不是復原前一個結果。比對方式和刪除確認的關鍵字相同（去掉標點與空白後完全相同，英文不分大小寫）。

固定的話先比對，再比對有 `<日期時間>` 的句型（「顯示完成」不會被當成 `顯示<日期時間>`）。

**編號**（見 [todos](todos.md) 的「編號」）：開頭的「將」和「把」相同。句子裡只有編號，沒有要從句子裡分出的內容，規則能完整解析。`<編號>` 是 `第N項`、`第N到M項`、`第N到第M項`、`第N項到第M項`，N、M 是阿拉伯數字或國字數字（「第三項」）；「第」「項」一定要有。結尾不去掉「呢」「嗎」（「刪除第3項嗎」是在問，不是要做）。

| 句型 | 指令 |
|---|---|
| `刪除<編號>`、`刪掉<編號>`、`<編號>刪除`、`<編號>刪掉`、`把<編號>刪除`、`把<編號>刪掉` | 刪除待辦（編號，照樣進入刪除確認） |
| `完成<編號>`、`<編號>完成`、`把<編號>設為完成` | 設定完成（編號，已完成） |
| `把<編號>移到<日期時間>`、`<編號>移到<日期時間>`，「移到」也可以是「改到」「延到」 | 修改待辦（編號，新日期是改寫後的 `<日期時間>`） |

沒有「第」「項」（「把3到10移到後天」）、辨識成別的字（「第三向」）都不命中，交給 AI。

**提示**（見 [help](help.md) 的「判斷」）：

| 話 | 指令 |
|---|---|
| 提示、幫助、說明、怎麼用、怎麼使用、如何使用 | 說明（總導覽） |
| `如何<頁名>`、`怎麼<頁名>`、`<頁名>怎麼用` | 說明（那一頁） |
| 上個提示 | 上個提示 |
| 下個提示 | 下個提示 |
| 還沒凍結的提示對話框目前那一頁的連結名稱 | 說明（那一頁） |

`<頁名>` 是 [help](help.md) 的「提示頁」裡的頁名。連結名稱只在一般判斷、快照裡最底下的提示對話框還沒凍結時比對。比對方式和固定的話相同，在固定的話之後、有 `<日期時間>` 的句型之前比對；頁名不和固定的話重複（見 [help](help.md) 的「提示頁」）。

**刻意不收**：用內容描述的新增、修改、設定完成、刪除，以及有內容關鍵字的查詢（「明天有什麼會議」）。這些要從句子裡分出待辦內容與內容關鍵字，規則保證不了正確；只用編號描述目標的不用分，所以收（見上面的「編號」）。查天氣只收上面兩句，其他說法交給 AI（見 [weather](weather.md) 的「判斷」）。

### 說法改寫

把口語的寫法改成日期與時間解析認得的書面寫法，業界稱為 inverse text normalization（ITN，反向文字正規化）。

只套用在 `<日期時間>` 那一段，規則和判斷提示詞的「寫法」相同（見 [date-time](date-time.md) 的「AI 的寫法」）。改寫後交給現有的日期與時間解析；解析本身不改。AI 輸出的 date、newDate 也套用同一份改寫（見 [judgment](judgment.md) 的「JSON 格式」）。

| 說法 | 改寫 |
|---|---|
| 國字數字（一～九、十、十一～三十一、兩），後面接年、月、日、號、點、分，或接在「月」後面 | 阿拉伯數字（「十一月」→「11月」、「七點」→「7點」、「兩點」→「2點」） |
| 號 | 日 |
| M月D，後面沒有接日、號、點 | M月D日（「10月12」→「10月12日」；接點時分不清是日還是時，不補） |
| H點半 | H點30分 |
| 星期X、禮拜X（X 是一～六、日、天） | 週X（天寫成日） |
| 上禮拜、這禮拜、下禮拜；上星期、這星期、下星期；這週 | 上週、本週、下週 |
| 上週X、本週X、下週X（X 是一～六、日） | 上週週X、本週週X、下週週X |
| 接下來、接下來一週、接下來七天 | 目前 |

### 紀錄

- 命中時，測試紀錄的「判斷」記一行 `規則：<指令摘要>`，例如 `規則：查詢待辦（10月6日）`；「校正」記 `規則判斷，不校正`；校正改了句子後才命中時，「校正」照樣記校正的結果。
- 沒命中不記，照原本的流程。

### 結構

規則判斷是 Domain 層的純函式：輸入一句話（拿掉空白後）、今天，與快照裡還沒凍結的提示那一頁的連結名稱（沒有就是空的），輸出一條指令或沒有；不依賴黑板與 AI（編號由執行器對到黑板）。是否完整解析由它呼叫日期與時間解析確認。

## Testing Decisions

- 單元測試（macOS）：
  - 每個句型與固定的話命中，產生的指令正確（含「今天會下雨嗎」「明天會下雨嗎」；「明天下午會下雨嗎」不命中）；結尾的「呢」「嗎」、標點。
  - 改寫表的每一列：「10月 6號」「下禮拜三」「十一月」「晚上七點半以後」「星期天」。
  - 編號：每個句型命中（單一、範圍、國字數字、「第N項到第M項」）；不命中：沒有「第」「項」、「第三向」、「刪除第3項嗎」、移到的日期解析不了。
  - 不命中：多了字（「明天要看牙醫」「明天有什麼會議」）、日期解析不了（「下下週有什麼事」）、「晚上是幾號」、「顯示過去項目」。
  - 提示：每種句型命中對的頁；「如何新增呢」命中；連結名稱只在有連結名稱時命中，只比對給的那幾個；「顯示」在沒有提示時不命中。
  - 流程：一般判斷命中時不呼叫校正與 AI 判斷；釐清中、刪除確認中命中時取消原本的任務並執行新指令；手動 AI 時命中不出現使用者提示詞；重試不調用。

## Out of Scope

- 用內容描述目標的新增、修改、刪除
- 有內容關鍵字的查詢
- 一句話裡有多條指令
