# 畫面

## Problem Statement

畫面主要用來看，操作用語音。使用者要看得到待辦、知道小精靈做了什麼；開發者要看得到每個階段的資料，並能不靠語音與自動 AI 穩定地重現測試。

## Solution

使用者畫面是一個區域固定的畫面，iOS 與 macOS 共用，iOS 直拿、橫拿都可以：由上而下是對話流、黑板（待辦清單）、按鈕列。macOS 在設定打開「除錯模式」時，使用者畫面在左、除錯 UI 在右（見 [settings](settings.md)）；iOS 沒有除錯 UI。

設計上語音可以完成所有操作，觸控是多給使用者的選擇。可以點的有：undo、redo、語音輸入開關、語音報告開關；判斷失敗彈窗的重試、略過；黑板上待辦的方框、上一頁與下一頁；對話流的新訊息橫條、提示對話框的箭頭與連結；工具列的提示按鈕、「顯示已完成」開關、打開設定的齒輪。看起來能點的就要能點。除錯 UI 是開發者的測試工具，不受這個限制。

黑板顯示目前專注的範圍：查詢的結果固定在黑板上，修改、刪除只在黑板上看得到的待辦裡找目標（見 [todos](todos.md) 的「黑板」）。

一句話：**區域固定：上面的對話流像聊天一樣看自己說了什麼、小精靈回了什麼，下面的黑板看目前專注的待辦。**

## User Stories

1. 作為使用者，我想查詢之後，結果留在畫面上，接下來的修改、刪除就針對我看到的這些。
2. 作為使用者，我想對話像聊天紀錄一樣固定：每句話後面就是小精靈對它的回話，往上捲看得到之前的對話。
3. 作為使用者，我想從回話知道小精靈接下來要做什麼、正在做什麼、做了什麼，或在問什麼；從回話旁的插畫看出它在思考、完成、聽不懂或等我回答。
4. 作為使用者，我想說話時即時看到小精靈聽到了什麼，也看得到哪些話還在排隊、還沒輪到。
5. 作為使用者，我想不知道該說什麼時，畫面告訴我下一句可以說什麼（見 [help](help.md)）。
6. 作為使用者，我想沒給提醒事項的權限時，開啟 App 就知道要去哪裡打開。
7. 作為使用者，我想畫面的區域不跳動，眼睛不用重新找位置。
8. 作為使用者，我想選擇要不要看已完成的待辦；範圍內過去的待辦一律看得到。
9. 作為使用者，我想回到上一個查詢的範圍，再回來。
10. 作為使用者，我想環境太吵時馬上關掉語音輸入。
11. 作為使用者，我想直接點方框把待辦設為完成，不用等 AI。
12. 作為使用者，我想一開 App 小精靈就跟我打招呼，順便告訴我一個用法或它自己的事。
13. 作為開發者，我想在除錯 UI 看到語音輸入、校正、判斷各自目前的資訊。
14. 作為開發者，我想在 Xcode console 看到每次處理的完整輸入與輸出。
15. 作為使用者，我想像提醒事項 App 的「排程」一樣，日期寫在分組標題上，近幾天用「今天」「明天」這類詞，一眼看出是哪天。
16. 作為使用者，我想每筆待辦前面有編號，說「刪除第 3 到 5 項」就能指定。
14. 作為開發者，我想打字取代說話，一次輸入多句，讓測試不受語音辨識影響。
15. 作為開發者，我想切換成手動 AI，把請求複製給手動 AI，再貼回它的 JSON。
16. 作為開發者，我想按一次就複製整次測試的紀錄，並能從相同的起點重新開始。

## Implementation Decisions

### 版面

區域的高度固定，不隨內容伸縮；內容放不下時在區域內捲動或截斷。內容改變時以淡入淡出過場。

| 區域 | 高度 |
|---|---|
| 對話流 | 約 42% |
| 黑板 | 剩下的空間 |
| 按鈕列 | 固定，貼底並避開 safe area |

不顯示標題（iOS 的導覽列、macOS 的視窗都沒有標題文字）；右上角的工具列由左而右是提示按鈕（`questionmark.circle`）、「顯示已完成」開關、語音報告開關與齒輪（`gearshape`）（提示按鈕見 [help](help.md)）（語音報告開關見 [spoken-report](spoken-report.md) 的「語音報告開關」）；「顯示已完成」開關見「黑板」；齒輪在 iOS 以 sheet 打開設定，macOS 打開設定視窗（⌘, 照樣可用）。

### 外觀

- 背景米白偏暖；元素有圓角與極輕的陰影。
- 支援淺色與深色模式，顏色定義成兩組 token；深色模式用暖深灰。強調色（按鈕、便條的圖示）是橘色。文字顏色和背景的對比至少 4.5:1（WCAG AA），淺色模式的橘色因此用較深的一階。
- 黑板是深綠底加木框，淺色與深色模式相同：文字是粉筆白，過去、已完成與時間用較淡的粉筆色，今天的日期用粉筆黃，查詢條件用淺藍。
- 字型用系統字。

### 對話流

大圓角的區域，在畫面最上方，像聊天一樣由上而下排列，在區域內捲動（捲動的規則見下面的「新內容」）。對話是一份照時間排列的紀錄，已經出現的話與回話位置不變，不存檔：

1. **開場問候**：開 App 時第一則回話，立刻顯示（內容見 [help](help.md) 的「開場問候」）。
2. **話與回話**：使用者的話是右邊的泡泡（有校正結果時是校正後的句子，見 [correction](correction.md)），輪到處理（目前的結果、插隊的回答）時出現；小精靈對它的回話是左邊的泡泡，接在那句話後面。觸控產生的回話（復原、重做、點方框、顯示已完成、觸控開的提示對話框）與「提醒事項有變動，已更新」（見 [storage](storage.md)）不屬於任何一句話，接在最後。
3. **排隊的話**：還沒輪到的句子（見 [queue](queue.md)），每句一個右邊的泡泡，用淡色泡泡加虛線框表示還沒送出；字維持一般顏色。
4. **正在說的話**：和排隊的話相同的樣式；確定結果一般顏色，暫定結果更淡。

一則回話從頭到尾只有一個泡泡，處理中原地更新內容：

- 輪到但還沒解讀好：「思考中…」
- AI 輸出指令後：接下來要做的指令
- 執行時：正在執行的指令
- 結束時：依任務結果產生的回報（例如「已新增 ☐ 10/3（六） 06:00 看牙醫」），有日期或時間的指令在回報上面先列出換算結果（例如「2026/11/15 15:30」「2026/01/02 ~ 2026/02/05」；完整的分析只記在測試紀錄，見 [todos](todos.md) 的「日期」），或釐清問題、刪除確認、取消／放棄的原因。修改、刪除找不到目標、查詢沒有結果時只說「找不到」。一句話有多條指令時，結果在同一則回話裡分段列出。
- AI 判斷沒有指令時：聊天的回應（見 [chat](chat.md)）；聊天失敗時是「聽不懂「<這句話>」」
- 說明、上個提示、下個提示：提示對話框，高度固定、可以原地換頁，下面出現新泡泡就凍結（見 [help](help.md) 的「提示對話框」）
- 查到天氣的回話，內容下面用小字顯示天氣資料的標示，一直跟著那則回話（見 [weather](weather.md) 的「標示」）；其他回話沒有標示
- 除了聊天的回應，不使用 AI 自己寫的文字：自動 AI 的文字會與實際結果不符（例如新增待辦後回報「已經買水果了」）。聊天不回報任務的結果，所以例外
- 開啟 App 時沒有提醒事項的權限或讀取失敗：開場問候之後一則回話「沒有取用提醒事項的權限，請到系統設定允許」或讀取失敗的原因（見 [storage](storage.md) 的「權限」）。這只是提示，不是釐清。

**小精靈的插畫**：每則回話左邊都有一張，照那則回話的狀態，換狀態時淡入淡出；回話結束後插畫就固定：

- 思考中（`elf_thinking`）：手托下巴。處理中的回話。
- 完成（`elf_done`）：坐著微笑。做完的回話、開場問候。
- 聽不懂（`elf_confused`）：攤手。聽不懂、錯誤確認。
- 等回答（`elf_listening`）：站著、雙手合十。釐清、刪除確認、「其他的也念出來嗎？」這些等使用者回答的回話。

沒有狀態文字；有沒有在聆聽看按鈕列的語音輸入開關。

**便條**：目前隱藏，對話從區域頂端開始（見 [help](help.md) 的「便條」）。顯示時：對話流頂端的置頂便條（橘色圖釘、半透明底），內容是操作的引導。它不是一句回話，所以不插進對話。便條佔住頂端的空間，對話從它下面開始，捲動時才從便條後面經過，不擋住對話。打開時一直顯示，有任務時也不消失；只有一行，超過寬度時截斷成「…」，不換行。工具列的便條開關關閉時不顯示，對話從區域頂端開始。

**新內容**：對話流變長時（新的話、回話更新、排隊的話、正在說的話），看的是變長之前的位置：

- 原本看得到最下面（或內容還不滿一頁）：跟著捲到最下面，沒有動畫。回話一段段更新時，動畫還沒結束下一段就到了，會被當成在往上看。
- 原本在往上看之前的對話：位置不動，對話流底部浮出新訊息橫條，像 LINE。橫條和便條同樣的樣式，一行，左邊是最新一則的插畫（小精靈的回話）或使用者泡泡的顏色（使用者的話），右邊是那則的文字，太長截斷成「…」；連續有新內容時換成最新的一則。點橫條捲到最下面；自己捲到最下面時橫條也收起。使用者自己說的話也一樣，不把畫面拉回最下面。

### 黑板

顯示黑板目前的一頁（範圍、查詢條件）與 checkbox（規則見 [todos](todos.md) 的「黑板」）。畫面上不出現「黑板」這個詞。

- 深綠底加木框（見「外觀」）。上方固定一列標題列與分隔線，只有清單在框內捲動。
- 標題列由左而右：上一頁（`chevron.left`）、標題、下一頁（`chevron.right`）、筆數。
  - 標題：範圍的說法與日期，例如「目前 10/2–10/8」「明天 10/3（六）」「下週 10/5–10/11」「這個月 10/1–10/31」「11月 11/1–11/30」「明年 2027」；指定範圍，以及新增、修改、刪除、undo／redo 平移後的範圍沒有說法，只有日期「10/3–10/9」「12/10–1/10」。範圍是「所有」時不顯示範圍。有查詢條件（時間範圍、內容關鍵字）時依序接在後面，用藍色，例如「下週 10/5–10/11 會議」「明天 10/3（六） 18:00 以後 會議」；時間範圍一律寫數字：「18:00 以後」「08:00 以前」「13:00–15:00」「15:30」。「所有」時只有藍色的查詢條件，例如「買水果」，沒有查詢條件時標題是空的（保留高度）。
  - 筆數：最右邊，黑板目前顯示的筆數，例如「12 筆」，較淡的顏色；沒有可顯示的待辦時是「0 筆」。範圍是「所有」、標題是空的時也顯示。
  - 沒有上一頁、下一頁時按鈕 disable。
- **「顯示已完成」開關**（參考提醒事項 App 的「顯示已完成」）：在工具列，不在黑板裡；它就是黑板的「完成」checkbox（見 [todos](todos.md) 的「黑板」），只是換了位置，行為與語音（「顯示完成」「隱藏完成」）不變。顯示時是 `checkmark.circle.fill`，隱藏時是 `checkmark.circle`；不顯示被隱藏的數量（參考提醒事項 App，只顯示總數量）；點擊範圍至少 44pt。讀取已完成的期間開關不能點。
- 清單依日期、時間由早到晚排列，沒有日期的待辦排在最底下（見 [todos](todos.md) 的「沒有日期的待辦」）。依日期分組（參考提醒事項 App 的「排程」），每組前面一個分組標題；沒有待辦的日子沒有標題。分組以今天為準，不看黑板的範圍：

  | 待辦的日期 | 分組標題 | 組裡的日期小標題 |
  |---|---|---|
  | 昨天、今天、明天、後天 | 「昨天」「今天」「明天」「後天」，只寫詞 | 沒有 |
  | 今天起 7 天內的其他日子，以及今天以前 7 天內 | `M/D（星期）`，一天一組 | 沒有 |
  | 這個月更後面的日子 | 「10月其餘」 | 有 |
  | 其他（其他月份，以及這個月今天以前超過 7 天） | 依月份：「11月」；不是今年時「2027年1月」 | 有 |
  | 沒有日期 | 「沒有日期」，在最底下 | 沒有 |

  - 分組標題：較淡的粉筆色、小一號字；「今天」用粉筆黃加粗，不只靠顏色區分（色盲、強光下也看得出來）。月份組的標題（「10月其餘」「11月」）是粉筆色、比待辦大一號字，和組裡的日期小標題分出兩層。
  - 日期小標題：月份組裡每換一天，在那天的待辦前面加一個 `M/D（星期）`，樣式和一天一組的分組標題相同；行裡不寫日期。
- 每行：編號、方框、時間、內容。內容折成多行時，編號、方框、時間對齊第一行。
  - 編號：黑板上的第幾筆（見 [todos](todos.md) 的「編號」），跨組連續；固定寬度靠右、較淡的粉筆色；不能點。
  - 方框：沒完成是 `square`、完成是 `checkmark.square`；點一下切換完成（見 [todos](todos.md) 的「黑板」）。
  - 時間：`HH:mm`，固定寬度；沒有時間的待辦空著，寬度保留，各行對齊。
  - 已完成的那一行整行較淡。
  - 已完成的以灰色、刪除線顯示。
- 沒有可顯示的待辦時顯示「無資料」。
- 不標示最近變動的待辦。
- 方框、上一頁、下一頁的點擊範圍至少 44pt。
- 目前的結果正在執行、等釐清或刪除確認、錯誤確認時，方框與「顯示已完成」開關不能點；背景在解讀後面的話不影響。上一頁、下一頁照常可以點。點方框、上一頁與下一頁都不中斷語音報告（見 [queue](queue.md) 的「觸控」）。

### 按鈕列

三個圖示按鈕，沒有文字，水平排列：復原（`arrow.uturn.backward`）、語音輸入開關、重做（`arrow.uturn.forward`）。語音輸入開關比另外兩個大；開著是 `mic.fill`、關著是 `mic.slash`。可以按的時機見 [recovery](recovery.md) 的「按鈕」。

**語音輸入開關**：和除錯 UI 的語音輸入開關是同一個狀態。App 啟動時打開，不存檔。

- 可以用語音關閉：語音定稿的一句話去掉標點與空白後完全等於「關閉語音」「停止聆聽」「關閉麥克風」之一時，立刻關閉，不排進佇列、不送 AI，任何狀態都適用。
- 關閉後不能用語音打開，只能按按鈕。

### 判斷失敗的彈窗

失敗的結果輪到時才跳出彈窗（背景失敗時不跳，見 [queue](queue.md)）：原因與「重試」「略過」兩個按鈕（見 [recovery](recovery.md)）。用語音重試、略過，或 undo／redo 離開錯誤確認時，彈窗也關閉。

### 除錯 UI

只在 macOS 打開「除錯模式」時顯示，接在使用者畫面的右邊。三欄並排，不捲動，所有資訊和操作一眼看完：左欄是控制、測試輸入、手動 AI；中欄是目前的資訊；右欄是測試紀錄，占滿剩下的空間。小精靈、待辦與補救按鈕只在使用者畫面，除錯 UI 不重複。

左欄最上方顯示自動 AI 的名稱與狀態（例如 Foundation Models 是否可用、上下文長度）。

**控制**：

- **語音輸入開關**：預設開。關閉就停止聆聽；送出測試輸入時自動關閉。關閉後不會自動打開。
- **自動 AI 開關**：預設開。關閉時改用手動 AI（見 [judgment](judgment.md) 的「判斷的來源」）。
- **測試清單開關**：預設關。打開時存檔只讀寫「VoiceTodo 測試」清單，並建立這個清單與測試待辦；關閉時刪除這個清單（見 [storage](storage.md) 的「測試清單」）。開關的狀態不存檔，App 啟動時一律關閉。
- **重新開始**：清空測試紀錄、三個佇列（和「全部取消」相同，見 [queue](queue.md)）、等待中的釐清、刪除確認、使用者提示詞與 undo／redo 的歷史，再從存檔重新讀取（見 [storage](storage.md) 的「重新開始」）；不改變開關。測試清單開關打開時，先把測試清單換回測試待辦，每次測試從相同的起點開始；關閉時不改變待辦。

**測試輸入**：多行文字框與「送出」按鈕（Enter 換行）。去掉空白行後，每一行是一句話，和語音定稿的一句話走相同流程，依序放進輸入佇列，在背景解讀、照順序呈現（見 [queue](queue.md)）。

**手動 AI**：目前等待的請求種類與請求文字（可選取複製）；AI 回應的文字框與「送出」按鈕。沒在等手動 AI 時顯示「—」。

**目前的資訊**（固定欄位）：

- **輸入**：即時的暫定結果、累積中的確定結果
- **佇列**：每句一行，句子編號與狀態，例如 `#3 目前（等回答）`、`#4 準備好`、`#5 判斷中`、`#6 排隊`（見 [queue](queue.md) 的「紀錄」）
- **校正**：最近一次的原文與結果（校正後文字、未修改、不採用或不校正的原因，見 [correction](correction.md)）
- **判斷**：指令清單、正在執行的指令、目前的釐清或刪除確認、每條指令的結果與結束方式；沒有指令時是聊天的回應或退回「聽不懂」的原因（見 [chat](chat.md)）

**測試紀錄**：表格，欄位為句子編號、階段、內容（見 [judgment](judgment.md) 的「紀錄」），範圍從 App 啟動或上次重新開始起。「複製」按鈕把整份紀錄複製成純文字，開頭是今天日期（含星期）與目前用的 AI（「AI：自動（<名稱>）」或「AI：手動」），設定的「預設提示詞」打開時接著是自動 AI 的固定提示詞定義（見 [judgment](judgment.md) 的「紀錄」），之後每行 `[#編號 階段] 內容`。表格不顯示固定提示詞的定義。同樣的內容也可以從設定分享（見 [settings](settings.md) 的「分享測試紀錄」）。

console 印出與測試紀錄相同的每一行，另外印出自動 AI 的詳細資訊（見 [judgment](judgment.md) 的「紀錄」）。

## Testing Decisions

- 手動驗證：
  - [ ] 排序正確；分組標題：昨天、今天、明天、後天只寫詞，7 天內一天一組，這個月更後面是「〇月其餘」，其他是月份，月份組裡每換一天有日期小標題、行裡不寫日期；「今天」是粉筆黃加粗；標題列右邊的筆數等於黑板上的待辦數（不算分組標題）
  - [ ] 編號從 1 開始、跨組連續；內容折行時方框對齊第一行
  - [ ] 黑板的範圍包含今天以前時，過去的待辦都顯示
  - [ ] 工具列的「顯示已完成」開關切換時，黑板顯示或隱藏已完成的待辦；第一次打開時讀取已完成的
  - [ ] 說話時即時顯示；連說幾句時，排隊的話是虛線的淡色泡泡，輪到處理才變成一般的泡泡
  - [ ] 回話或句子很長時，區域高度不變；往上捲看得到之前的對話
  - [ ] 在最下面時，新的話與回話（包括一段段更新、出現天氣標示）都跟著捲到最下面
  - [ ] 往上看之前的對話時，有新內容不會被拉走，底部浮出新訊息橫條；點它或自己捲到最下面，橫條收起
  - [ ] 淺色與深色模式都清楚
  - [ ] 新增、修改、設定完成、刪除後清單隨即更新
  - [ ] 開 App 時第一則是開場問候，有插畫，沒有狀態文字
  - [ ] 一則回話原地依序顯示思考中、計畫、執行中、結果；下一句話輪到時，上一則回話留在原位，插畫不再變
  - [ ] iPhone SE 上黑板至少看得到 5 行
  - [ ] 查詢後黑板移到那個範圍，上一頁、下一頁可以來回
  - [ ] 重開 App 黑板在上次最後的那一頁（範圍與查詢條件），沒有上一頁；隔天重開時「目前」從今天起算，其他說法拿掉、只剩日期
  - [ ] 點方框切換完成，可以 undo
  - [ ] 說「關閉語音」立刻停止聆聽
  - [ ] 複製的測試紀錄貼到文字編輯器後，一句話的經過完整可讀

## Out of Scope

- 上面列出的觸控以外，任何點擊、鍵盤操作；新增、修改內容、刪除待辦只用語音
- 小精靈說話（TTS）與動畫
- 手寫或粉筆字型
- 測試紀錄存檔
- 行事曆檢視（年曆、月曆）
